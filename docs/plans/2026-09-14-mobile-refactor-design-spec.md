## 1. 규칙 여덟

각 규칙은 **무엇을 하는가**와 **무엇을 하지 않는가**를 함께 갖는다. 하지 않는 쪽이 빠지면 규칙은 다음 세션에서 조용히 넓어진다.

### 규칙 1 · 층은 넷이고 순서는 고정이다

콘텐츠 → GNB → **배너** → **오버레이**. 배너는 스크림이 없고 배경이 스크롤된다. 오버레이는 스크림이 있고 배경을 잠근다.

**하지 않는 것.** 배너와 오버레이가 컨테이너를 공유하지 않는다. 동의 UI 를 오버레이로 만들지 않는다. 배너를 GNB 아래 층에 두지 않는다.

### 규칙 2 · 마찰은 앞으로 갈수록만 무거워진다

랜딩 도착 **0**(배너) → 카드 탭 **1**(오버레이, 쉽게 닫힌다) → instruction **2**(모달, 선택을 강제한다).

**하지 않는 것.** 아직 아무것도 하지 않은 사용자에게 화면 전체를 덮지 않는다. 역방향으로 무거워지는 화면을 만들지 않는다.

### 규칙 3 · 형태는 공간이, 닫는 법은 입력이 정한다

폰(1 열)의 카드 확장은 **바텀시트**다 — 하단에서 올라오고, grabber 를 갖고, 닫기 컨트롤 44×44 · backdrop 탭 · 스와이프 다운 · `Escape` · 시스템 뒤로가기로 닫힌다. 열린 동안 배경을 잠근다.

태블릿·데스크톱(다 열)의 카드 확장은 **제자리 오버레이**다 — 카드가 그 자리에서 커진다. 위치를 옮기지 않는다.

닫는 법만 입력이 정한다. hover 가 없는 기기에는 **dim backdrop** 이 깔리고 **빈 곳 탭이 닫기**다. hover 가 있는 기기는 포인터 이탈로 닫힌다(현행 유지). `Escape` 는 모든 조건에서 닫는다.

**하지 않는 것.** 태블릿·데스크톱 확장을 하단으로 옮기지 않는다. **제자리 오버레이에 닫기 X 를 두지 않는다** — 카드 밖이 곧 닫기 영역이므로 X 는 중복이다.

### 규칙 4 · 동의는 두 얼굴을 갖지 않는다

하단 배너 하나다. 사방에 여백을 두고, 스크림이 없고, 뒤에서 카탈로그가 계속 스크롤된다. **제목 없이 본문 한 단락 + 버튼 둘.**

`Allow` 는 CTA(채운 sage). `Deny` 는 **평문 텍스트 버튼**이다 — 시각 무게가 낮아야 누르기 꺼려지고 그것이 의도다. `Preferences` 버튼은 없앤다.

**하지 않는 것.** 제목 줄(`Allow optional cookies?` 류)을 넣지 않는다. `Not now` 같은 중립어를 쓰지 않는다 — 부정의 의미가 전달돼야 한다. 두 버튼의 무게를 같게 만들지 않는다.

### 규칙 5 · 주장이 둘이면 마크도 둘이다

「내가 고른 것」(`preference`)과 「지금 적용 중인 것」(`effective`)은 서로 다른 주장이다. 한 마크가 둘을 겸직하면 `System` 을 표현할 자리가 없어진다.

- **명시 선택**(preference = light 또는 dark): 고른 쪽이 **일반적인 selected 형태**를 갖는다 — 얇은 단일 sage 링. **점은 붙이지 않는다**: 고른 것이 곧 적용 중인 것이라 구분할 것이 없다.
- **System 선택**(preference = system): `System` 이 **선택됨 칩**(`--sage-muted` 바탕 + `--accent-fg` 잉크 + 체크 글리프)을 입는다. 시스템이 해석한 쪽 스와치에 **배지 점**(sage, 스와치 우상단, `--surface-raised` 2px 외곽)이 붙는다 — 덜 강조되지만 읽히고 **누를 수 있다**. 반대편 스와치는 마크가 없어 **selectable** 로 읽힌다.

**하지 않는 것.** 링을 이중(2px 흰 간격 + 2px sage)으로 그리지 않는다 — 과하다. 색만으로 상태를 구분하지 않는다(WCAG 1.4.1) — 선택됨은 색 + 체크, 적용 중은 색 + 점의 존재로 말한다. 적용 중인 쪽을 `disabled` 로 만들지 않는다.

### 규칙 6 · 마크는 레이아웃을 건드리지 않는다

선택·활성 표시는 `box-shadow` 와 절대 위치로만 그린다. `border` 폭을 바꾸면 박스가 커져 **같은 행의 형제가 어긋난다.** 한 행의 컨트롤은 높이 하나, 기준선 하나다.

**하지 않는 것.** 선택 상태에서 `border-width` 를 바꾸지 않는다. `outline` 으로 간격을 만들어 행 높이를 늘리지 않는다.

### 규칙 7 · 손이 닿는 곳에 자주 쓰는 것을 두고, 자주 쓰지 않는 것은 조용하다

모바일 드로어는 **이동(Home·History·Blog)이 최하단**, 자주 바꾸지 않는 **설정이 최상단**이다. 엄지가 닿는 자리를 이동이 갖는다.

자주 쓰지 않는 것은 무게를 낮춘다. 동의 수정은 **행을 차지하지 않는 우측 정렬 얇은 링크**다. 데스크톱 설정 트리거는 **테두리도 배경도 없이** 옆의 `History`·`Blog` 텍스트 링크와 같은 무게로 선다.

**하지 않는 것.** 설정·동의 수정을 드로어 최하단에 두지 않는다. 동의 수정 링크를 버튼이나 칩으로 만들지 않는다. 데스크톱 설정 트리거에 테두리·배경·굵은 글씨를 주지 않는다.

### 규칙 8 · 레이어는 자기 트리거를 덮으며 펼쳐진다

설정 레이어의 **우측 상단 모서리가 트리거 pill 의 우측 상단 모서리와 일치**한다. 레이어는 **pill 을 덮으며** 아래·왼쪽으로 펼쳐진다.

**하지 않는 것.** 레이어를 pill 아래에 간격을 두고 띄우지 않는다. **선택 값에 따라 좌우 위치가 바뀌지 않는다** — 같은 것을 두 번 열면 같은 자리에 있어야 한다.

## 2. 표면별 확정 명세

### 2-1. 첫 진입 (모바일)

하단 배너. 사방 여백. 본문 한 단락 + `Allow`(CTA) + `Deny`(평문 텍스트). 뒤에서 카탈로그가 스크롤된다.

카드의 부제(description)는 모바일에서 **최대 두 줄까지 허용**한다 — 현재는 한 줄이다. 두 줄을 넘으면 자른다.

### 2-2. 동의 미선택 상태에서 카드 탭 (모바일)

사전질문 바텀시트가 **배너보다 위 층**에 뜬다. 배너는 스크림 아래에 **그대로 남는다** — 사라졌다 돌아오지 않는다. 두 UI 는 **컨테이너를 공유하지 않는다.**

동의 미선택 상태로 사전질문에 답하는 것은 **허용된다.**

### 2-3. instruction (모바일) — 현행 유지

동의와 응답 전 안내를 통합한 현행 모달 시트를 **그대로 둔다.** 마찰 사다리의 마지막 칸이고, 여기서는 선택을 강제하는 것이 맞다.

**한 가지만 고친다.** GNB 의 화면 제목이 좌측 `Back` 버튼이 침범한 영역 안에서 중앙 정렬돼 시각적으로 어긋나 있다. **제목은 컨테이너 전체 폭을 기준으로 중앙 정렬**하고, `Back` 버튼은 그 위에 절대 위치로 얹는다.

### 2-4. GNB 드로어 (모바일)

위에서 아래로: **헤더**(보이는 닫기 컨트롤, 우측) → **설정 블록** → 여백 → **이동 블록**(최하단).

설정 블록은 `Settings` 라벨 + 테마 컨트롤 한 행(`System` 텍스트 버튼 · dark 스와치 · light 스와치) + **언어 칩 12 개 전부**(형태 그대로) + 그 아래 **우측 정렬 얇은 링크** `Privacy preferences`.

이동 블록은 `Home` · `History` · `Blog` 52px 행이고 현재 위치가 sage 로 표시된다.

**함께 고치는 것.** `aria-modal` 이 사실이 되도록 **포커스 트랩**을 건다(현재 Tab 20 회 중 5 회가 드로어 밖으로 샌다). `h-screen max-h-screen` 두 유틸리티를 지워 `100dvh` 를 살린다.

**하지 않는 것.** 언어 칩을 접거나 줄이지 않는다. 가운데 여백을 이번에 채우지 않는다 — 진행 중인 회차·최근 결과·읽을거리 노출은 **모바일 최적화가 끝난 뒤** 따로 정한다.

### 2-5. 동의 재호출

얇은 링크를 누르면 **같은 배너가 그대로** 다시 뜬다. 새 화면을 만들지 않는다. 이전 선택을 표시한다.

- `Allow` 를 골랐던 경우: CTA 안에 **흰 체크 글리프**가 들어간다.
- `Deny` 를 골랐던 경우: 평문 버튼이 **선택됨 칩**(`--sage-muted` + `--accent-fg` + 체크)을 입는다.

두 경우 모두 `Allow` 는 CTA 형태를 잃지 않는다 — 재호출에서도 제품은 동의 쪽을 권한다.

진입점은 둘이다. 모바일은 드로어 설정 블록의 우측 정렬 링크, 데스크톱은 **페이지 최하단 중앙**의 같은 링크다.

### 2-6. 결과 화면 — 주소까지만

`req-test.md` §5.1 의 Result URL 을 구현한다. 그것만으로 **공유·새로고침 복원·뒤로가기**가 열린다. GNB 문맥을 전환해 진행률·타이머를 걷는다.

**하지 않는 것.** 결과 화면의 **내용 구성을 만들지 않는다**(타입·축 차트·설명). **동적 OG 카드를 만들지 않는다.** 둘 다 다음 phase 소유다.

### 2-7. 히스토리 — 목록까지만

실제 회차를 목록으로 렌더한다 — 테스트 이름 · 시각 · 중단 여부. 디버그 문자열 `Locale: en` 을 제거한다. 빈 상태에 다음 행동(테스트 둘러보기)을 준다.

**하지 않는 것.** 항목을 눌렀을 때의 동작과 URL 스킴을 만들지 않는다 — 결과 화면 내용과 함께 다음 phase 다.

### 2-8. 에러 · 404

`/test/error` 의 하드코딩 한국어 제목을 메시지 키로 옮겨 12 locale 번역한다. 본문에 **앞으로 가는 경로를 최소 하나** 둔다. variant 식별자를 사용자 화면에서 빼고 registry 멤버십을 확인한다. 같은 규율을 **세그먼트 404 두 장과 Next 내장 오류 폴백**에도 적용한다.

### 2-9. 데스크톱 우측 상단 설정

**닫힌 트리거**는 조용한 pill 이다 — 테두리 없음, 배경 없음, **언어 전체 이름**(`English`, `한국어`, … — 코드 약어를 쓰지 않는다), `font-weight` 기본값, 잉크 `--ink-body`, 그 뒤에 1px 구분선과 현재 테마 글리프. 높이 36px. hover 에서만 `--surface-muted` 가 들어온다.

**열린 레이어**는 규칙 8 을 따른다 — 우측 상단 모서리를 pill 의 우측 상단 모서리에 맞추고 **pill 을 덮으며** 펼쳐진다.

레이어 내용은 `Settings` 라벨 + 테마 컨트롤 한 행 + 언어 칩 12 개. 테마 컨트롤은 왼쪽부터 **`System` 텍스트 버튼 · dark 스와치 · light 스와치**이고 규칙 5·6 을 따른다.

### 2-10. 데스크톱 최하단

페이지 최하단 **중앙**에 `Privacy preferences` 얇은 텍스트 링크 하나. 위아래 여백을 최소로 준다. 잉크는 `--muted` 보다 더 흐린 회색으로 — 콘텐츠의 끝맺음으로만 읽혀야 한다.

**하지 않는 것.** 데스크톱에 동의 수정 진입점을 이것 말고 더 만들지 않는다.

### 2-11. 터치 태블릿 (768~1024, hover 없음)

카드 확장의 **위치는 그대로**다 — 제자리 오버레이. 더해지는 것은 **dim backdrop** 하나이고, 그것이 층을 읽히게 하는 동시에 **닫기 영역**이 된다. 빈 곳을 탭하면 닫힌다. `Escape` 도 닫는다.

이 표면의 우측 상단 설정 pill 도 **언어 전체 이름**을 쓴다.

세로에서 가로로 돌린 폰이 이 조건으로 들어온다. 회전으로 펼친 카드가 파괴되지 않는 것을 **E2E 로 고정**한다.

## 3. 전 표면 공통

### 3-1. GNB 컨트롤 — 보이는 것과 만지는 것을 분리한다

바 높이는 모바일 56px · 데스크톱 64px 그대로. **보이는 껍데기는 36px**, **히트 영역은 44px**(투명 여백). 텍스트 크기는 15px 그대로다. 위아래 여백이 6px 에서 10px 이 된다.

이 규칙은 GNB 의 모든 컨트롤에 같이 적용된다 — `Menu` · `Back` · 데스크톱 설정 pill · 드로어 헤더의 닫기.

### 3-2. 설정 라벨은 `Settings` 다

데스크톱 레이어와 모바일 드로어 모두 `Settings` 를 쓴다. 종전의 `LANGUAGE · THEME` 는 좁은 폭에서 **두 줄로 접힌다.**

### 3-3. 확장 메타 행

`소요시간 · 완료수` 는 **왼쪽**, `공유수` 는 **오른쪽 정렬**. 폰 시트와 태블릿·데스크톱 제자리 오버레이가 같은 규칙을 쓴다.

예: `3 min · 15,236 completed` &nbsp;&nbsp;…&nbsp;&nbsp; `2,184 shared`

| 1 | 제목이 한쪽으로 밀려 보인다 | 절대 위치 형제(좌측 버튼)가 침범한 영역 **안에서** 중앙 정렬했다 | **중앙 정렬의 기준은 언제나 컨테이너 전체 폭**이다. 겹치는 컨트롤은 절대 위치로 얹는다 |
| 2 | 같은 행의 형제가 세로로 어긋난다 | 선택 마크를 `border` 폭으로 그려 박스가 커졌다 | 마크는 `box-shadow`·절대 위치로만. `border-width` 를 상태로 쓰지 않는다 |
| 3 | 한 줄이어야 할 라벨이 두 줄로 접힌다 | 라벨이 컨테이너보다 길다 | 라벨을 줄이거나 컨테이너를 넓힌다. 접힘을 방치하지 않는다 |

**착수 전에 이 표를 읽고, 표면을 하나 끝낼 때마다 셋을 대조한다.**
