Two mismatches that are not the legacy theme

Both are the product's own code disagreeing with its own design intent, so neither belongs in the table above and neither resolves in the theme cut. D-06 design.md §4.3 states one global wrapping rule: word-break: keep-all; overflow-wrap: anywhere. Applies it to the expanded question and the choice text unconditionally, and to the card title and subtitle only on the mobile tier (module.css:96-100). Above mobile they carry overflow-wrap alone (tsx:212, :214).

Measured 2026-09-07, not inferred. Of the eight catalog cards, five wrap and four break Korean mid-word on the desktop tier today — egtt 카탈로그에 / 서는 · ops-handbook 준비할 / 지, 갖 / 춰야, 또 / 한, 데스크톱 / 과 · build-metrics 테스 / 트, 실용 / 적인 · release-gate 쌓 / 아. Every one of them moves to a word boundary under keep-all. The mobile control has the rule and breaks correctly.

The one objection to applying it at every tier does not hold. A card carrying a long unbreakable Latin token produces byte-identical line boxes with and without keep-all — overflow-wrap: anywhere still handles it. The pair §4.3 specifies fixes Korean without regressing the long-token case. This system follows the intent, so both bases carry both properties.
D-07 The blog Read more → fades in over 140ms — transition-opacity duration-[140ms] on the element itself. It did not fade, and now it does. The same element also switched display (module.css:144-150), and an element with no rendered previous frame cannot transition, so the reveal was instant in both directions. Resolved 2026-09-07: the fade is kept and driven by opacity + visibility. Traced along the curve in this bundle — 0 → 0.607 → 0.878 → 0.975 → 1 across the 140ms — where the shipped mechanism reports zero running animations.

A second reason found while checking the first. display: none takes the CTA out of layout, so wherever it would compete with the tag row the reveal reflows that row: measured at 250px, the tags lose 23.33px and the last tag ellipsizes a further 3.92px under the pointer. The visibility mechanism reserves the box and measures zero shift at 397, 292 and 250px. visibility rather than opacity alone because it also keeps the hidden CTA out of the tab order and the accessibility tree, which display: none was doing. Runtime change is step 5.
