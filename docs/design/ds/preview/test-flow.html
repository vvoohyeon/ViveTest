What changed, and why

Three geometry values came off the ramp. The realized surfaces use 18px radius for panels, 16px for shell cards and 14px for every button. The VIVE ramp is 5 / 8 / 12 / 16 / 24 / 999 — only 16 is on it. Panels move to --radius-lg (16), dialogs and drawers to --radius-xl (24) per §6.8, buttons to --radius-md (12). The one realized value kept as-is is min-height 46px on buttons: it is off the 4px grid but it clears §4.10's 44px floor, and a real value that satisfies a real rule is not worth rounding.

The answer button was already decided. Step 2 established .vt-choice--answer — the catalog's choice row with a radio mark instead of an arrow — and the filled CTA for submit. Nothing here revisits that; the question surface just uses it. What is new is the third button weight, .vt-btn--quiet, which the flow needs and never had: "Deny and start" was rendering with the same neutral fill as "Previous", so a consent refusal and a navigation step carried identical visual weight.

Placeholder copy is out of scope and stays visible. The history page renders Locale: en as body text, the test-error heading is a hardcoded Korean string served to all twelve locales, and both 404s are hardcoded English with no shell. Those are content defects, not visual ones; they are recorded in the extraction and left for the owner of those strings rather than designed around.
