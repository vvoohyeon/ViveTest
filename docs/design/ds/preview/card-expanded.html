Fixed by req-landing.md §8.4 and frozen under decision B. There is deliberately no --shell-scale token — this is behaviour, not a visual choice, and a token would invite someone to change it. Constants at layout-plan.ts:10-11, base at :123, resolution at :139.

The height floor is a measured pixel value, and saying it as min-height: 100% is banned by name — design.md §7.3, and again in its §10 Never list. The product measures the resting card, divides by the base shell scale, and writes the result inline (landing-grid-card.tsx:837, value at :995); the shell's own 1.04 then puts the visual floor back on the resting card's height. The specimens above carry min-height: calc(270px / 1.04) for exactly that reason — the same arithmetic, on the same box. Surplus above the floor goes to one place only: the spacer between the last choice and the meta row, min-height: 14px; flex: 1. Not to a gap, not to a margin, not spread through the stack.
